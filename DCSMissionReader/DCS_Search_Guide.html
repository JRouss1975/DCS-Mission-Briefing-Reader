1. Overview

DCS Mission Briefing Reader supports three layers of search that work together:

  1. Structured Filters — precise key:value pairs for aircraft, map, mission type, side, time, country, and file-name similarity.
  2. Auto-Detection — plain words like syria, viper, sead, or night are recognized automatically as structured filters without needing the key: prefix.
  3. Free-Text Search (FTS5) — any remaining unrecognised words are searched across briefing text, task descriptions, unit names, sortie, file name, tags, and theatre — all at once.

Words that are recognised by auto-detection are removed from the free-text search and applied as precise structured filters instead. This means f16 sead syria searches only for missions with an F-16 on the Syria map doing SEAD — not every mission that happens to mention those words in the briefing.

Tip: You can mix all three approaches in a single query: plane:f16 syria night "protect the convoy" filters by F-16 on Syria at night, and also searches the briefing text for "protect the convoy".

2.8 Negation / Exclusion — -word or !word

Prefix any plain word with - or ! to exclude missions matching that term. The same auto-detection rules apply: aircraft, map, mission type, time, side, or free-text.

QueryWhat it does
f16 -seadF-16 missions, excluding SEAD type
syria -carrierSyria map, no carrier-capable aircraft

caucasus -f16 -a10Caucasus, excluding both F-16 and A-10
f16 -convoyF-16 missions, excluding any mentioning "convoy" in text
Tip: Exclusions stack with all other filters. You can combine structured filters, auto-detected terms, free-text, and exclusions freely.

3. Auto-Detection — Plain Text Keywords

When you type a plain word (without key:), the parser checks it against the following dictionaries. If matched, it becomes a structured filter instead of a free-text term.

Important: Auto-detected words are removed from the free-text search. If you want to search for the word "syria" inside the briefing text (not as a map filter), use quotes: "syria".

3.1 Aircraft Auto-Detection

Any plain word matching a known aircraft name or nickname is treated as a plane: filter. This includes all the nicknames and codes listed in section 2.2. Variant suffixes are also matched (e.g., f15c, f16c, mig29s, f4e).

Examples: 
viper sead syria      ← viper → plane filter, syria → map filter, sead → type filter
f18 cap               ← f18 → plane filter, cap → type filter
f15c night             ← f15c → plane filter (StartsWith "f15"), night → time filter
apache caucasus       ← apache → plane, caucasus → map

4. Free-Text Search (FTS)

Any words that are not recognised by auto-detection become free-text terms. The FTS5 engine searches them simultaneously across ALL of the following fields:

FTS ColumnWhat it contains
nameMission file name (hyphens/underscores → spaces)
sortieSortie number / description
briefingFull briefing text: Situation + Blue Task + Red Task + Neutrals Task
unitsAll unit names, types, and callsigns across all coalitions
tasksAll group task names across all coalitions (CAP, SEAD, Ground Attack, etc.)
tagsMission tags (parsed from tasks text + AI-tagged, if any)
theatreTheatre / map name
Tip: FTS uses unicode61 remove_diacritics 2 tokenizer — it handles accented characters (Greek, etc.) automatically, matching both accented and unaccented forms.

Search Behaviour

  • Prefix matching: Terms of length ≥ 3 are automatically stem-wilded: f16 matches f16, f16c, f16a, etc.
  • AND first: The search first tries to find missions matching ALL terms. If no results, it falls back to OR.
  • Spelling correction: If AND and OR both return zero results, the system tries to correct misspelled words using the FTS5 vocabulary.
  • Quoted phrases: Use "exact phrase" to match a specific sequence of words in the briefing text.
Examples: 
protect the convoy               ← searches "protect" + "convoy" in briefing/tasks/units
"destroy sam site"               ← exact phrase match in briefing text
escort bomber                    ← searches "escort" + "bomber" in all FTS columns

6.2 Combining All Techniques

You can freely mix structured filters, auto-detected words, and free-text in any order:

Complex examples: 
plane:f16 sead syria "destroy sam"       ← F-16, SEAD, Syria, free-text "destroy sam"
f18 cap night "protect the carrier"      ← F-18, CAP, night, free-text phrase
type:csar helo gulf "extract downed"     ← CSAR, helicopter, Gulf, free-text
like:"op persian" side:blue              ← similar file names + blue coalition
f15e strike "deep strike"                ← F-15E, STRIKE type, free-text phrase

6.3 Stop Words

The following common words are ignored and do not affect search results:

English: the, a, an, and, or, of, to, in, on, at, for, with, from, by, is, are, mission, missions, vs, versus, any, all, some, my, me, find, search
Greek: με, και, στο, στη, στην, στον, το, τα, η, ο, οι, του, της, των, για, απο, σε, ενα, μια, αποστολη, αποστολες, βρες, ψαξε, θελω

6.4 Negation / Exclusion — - and !

Prefix a word with - or ! to exclude missions that match it. Works with all auto-detected categories and free-text:

QueryEffect
f16 -seadF-16 missions, excluding SEAD
syria -carrierSyria missions, excluding carrier ops
f18 -nightF/A-18 missions, daytime only
caucasus -f16Caucasus missions, no F-16
sead -syriaSEAD missions, not on Syria map
f16 -convoyF-16 missions, exclude any that mention "convoy" in briefing
Note: Excluded terms are applied after the main search, both as structured filters (aircraft, map, type) and as free-text FTS negation. You can mix multiple exclusions per query.

6.5 Using Quotes for Literal Text Search

If you want to force a word to be searched as free text in the briefing (rather than being auto-detected as a filter), wrap it in double quotes. This is useful if the word happens to be a known DCS term but you want it matched in text.

Example: 
"syria"                                  ← searches for "syria" in briefing text, NOT as a map filter
"viper" sead                             ← searches "viper" as text, "sead" as type filter

8. Force Re-Index (Reset Cache)

If the index becomes corrupted or you want to force a complete re-index from scratch:

  1. Close the application — the database file is locked while the app is running.
  2. Delete the file: 
    %LOCALAPPDATA%\DCSMissionReader\missionindex.db

    Which typically resolves to:

    C:\Users\<YourUsername>\AppData\Local\DCSMissionReader\missionindex.db
  3. Restart the application — it will automatically re-index all mission files on the next folder load.
Tip: You can also delete this file while the app is running if you want to force a re-index. Simply select the missions folder again from the "DCS MISSIONS FOLDER" button in the status bar.
